# Learning-first approach
- Never write code without explaining the concept first and getting permission
- Explain line-by-line when asked — teach the *why*, not just the *what*
- Keep code comments minimal — only where truly necessary
- Build step by step: concept → discussion → code → test
- This is a 12-week learning project, not a code dump

# Quota & API Constraints
- Hard daily quota: 500 requests per day.
- Conserve API calls: use dry-runs, unit tests, and targeted single-prompt tests during development.
- Reserve full 25-case eval runs for milestone verification.
